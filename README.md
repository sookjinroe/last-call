# LAST CALL — 매장 칵테일 슬롯

방문 손님에게 무료 코인 10개를 주고, 당첨되면 메뉴 경품을 드리는 슬롯 게임이에요.
손님은 아무것도 걸지 않고, 코인은 판매하거나 다른 것으로 바꿔 주지 않아요.

- `index.html` — 손님 폰 게임 (입장 QR로만 시작)
- `owner.html` — 사장님 아이패드: 입장 QR 만들기, 경품·알림 설정 (Face ID / Touch ID, 예비 PIN)
- 알림: [ntfy](https://ntfy.sh) 앱으로 사장님 폰에 입장·당첨·종료 알림

## 처음 설정
1. 아이패드 사파리에서 `https://sookjinroe.github.io/last-call/owner.html` 열기 → 공유 → 홈 화면에 추가
2. Face ID / Touch ID 등록 → 예비 PIN 4자리 → 사장님 폰에 ntfy 앱 설치 후 화면에 나온 채널 구독 → 테스트 알림 확인

## 손님이 올 때
1. 아이패드에서 "입장 QR 만들기" → 생체인식 → QR 보여 주기 (2분 뒤 만료)
2. 손님 폰으로 찍고 테이블 번호·닉네임 입력 → 코인 10개
3. 당첨되면 사장님 폰에 `테이블 5 · 민수 — 군만두 당첨 (쿠폰 4821)` 알림, 아이패드 화면에도 테이블별 카드로 표시
4. 손님 화면의 쿠폰 번호를 확인하고 경품 지급 → 아이패드 카드에서 "지급" 누르기
