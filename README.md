# LAST CALL — 매장 칵테일 슬롯

테이블 QR을 찍은 손님이 무료 코인 10개로 슬롯을 돌리고, 당첨되면 메뉴 경품을 받는 게임이에요.
손님은 아무것도 걸지 않고, 코인은 판매하거나 다른 것으로 바꿔 주지 않아요. 테이블당 1회만 참여할 수 있어요.

| 파일 | 용도 |
|---|---|
| `index.html` | 손님 게임 (테이블 QR `?t=번호`로 입장) |
| `owner.html` | 사장님 화면 — 테이블 지도, 경품 지급, 테이블 비우기, 설정 (폰·아이패드) |
| `stickers.html` | 테이블 QR 스티커 인쇄 |
| `apps-script/Code.gs` | 구글 시트에 붙이는 코드 (테이블 상태·쿠폰·기록 저장, 사장님 폰 알림) |
| `config.js` | 시트 웹 앱 주소 |

## 처음 설정

### 1. 구글 시트에 코드 붙이기
1. 구글 드라이브에서 **LAST CALL 슬롯 관리** 시트를 열어요.
2. 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣은 뒤 저장(💾)해요.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인(구글 계정 선택 → "고급" → "안전하지 않은 페이지로 이동" → 허용). 내가 만든 코드라 괜찮아요.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 `config.js`에 넣어요.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요. 주소는 그대로예요.

### 2. 사장님 화면
1. 폰·아이패드에서 `https://sookjinroe.github.io/last-call/owner.html`을 열고 **홈 화면에 추가**
2. 시트 **설정** 탭의 **관리키**를 입력
3. **설정**(처음에 설정 PIN 4자리를 정해요)에서 ntfy 채널을 사장님 폰 ntfy 앱으로 구독 → 테스트 알림 확인

### 3. 테이블 QR
사장님 화면 아래 **테이블 QR 스티커 인쇄** → 인쇄해서 잘라 각 테이블에 붙여요.

## 영업 중
- 손님이 테이블 QR을 찍고 닉네임을 넣으면 바로 코인 10개로 시작 (사장님 폰 알림)
- 이미 참여한 테이블은 손님 폰에 바로 "이미 참여했어요"가 떠요
- 당첨되면 사장님 화면 테이블 카드에 쿠폰이 생기고 알림음 → 직원이 경품을 테이블로 가져다주고 **지급** (손님 화면에 "받음 ✓"이 떠요)
- 손님이 떠나면 테이블 카드의 **새 손님 받기**로 비워요 (깜빡해도 마지막 활동 3시간 뒤 자동으로 비워져요)
- 모든 기록은 구글 시트의 쿠폰·기록 탭에 쌓여요
